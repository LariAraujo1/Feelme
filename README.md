## 🎬 FeelMe - Escolha seu filme pelo humor!

O FeelMe é uma aplicação web interativa que combina HTML, CSS e JavaScript para oferecer recomendações cinematográficas personalizadas conforme o humor do usuário, integrando um sistema de autenticação simples e uma interface intuitiva que exibe capa, nome e sinopse dos filmes sugeridos.

## ⚡ Funcionalidades:

- **Escolher humor:**
Alegre • Reflexivo • Melancólico • Nostálgico
Inspirador • Sonolento • Sombrio • Aleatório

- **Cadastro/login:**
Crie uma conta ou faça login com e-mail e senha.

- **Recomendações:**
Veja o nome, capa e sinopse do filme sugerido para seu humor.

## 🛠️ Tecnologias utilizadas
HTML • CSS • JavaScript
